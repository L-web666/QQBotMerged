❓ 使用说明

        

          
        

      

      

        
⏻ 关闭程序

        
点右上角「关闭程序」会停止所有机器人连接与网页服务并退出进程。
          程序不会自动重启（若用 start.bat 启动，退出后会被脚本重新拉起，
          需要停掉脚本窗口）。

      

      

        

          
🚀 快速开始

          
    
            
  1. 在「设置 → 机器人账号」里填 AppID / AppSecret 并勾选启用（可配多个机器人，各自独立连接）。
    2. 
            
  2. 在「设置 → AI 服务」里填 API Key / 接口地址 / 模型（任意 OpenAI 兼容服务）。
    3. 
            
  3. 保存后需要重启程序的项会明确列出；其余项保存即生效。
    4. 
            
  4. 用 QQ 私聊机器人或在群里 @ 它，消息就会出现在「聊天窗口」。
    5. 
          

        

        

          
💬 聊天窗口

          
    
            
  • 顶部切换机器人；左侧按群聊/私聊分组，带未读计数。
    • 
            
  • 发送支持：文本、图片链接、本地上传图片/表情包、任意文件。
    • 
            
  • 点击任意消息会弹出操作框：可引用该消息、复制内容、查看原始数据、撤回等。
    • 
            
  • 清空记录：会话内 🧹 按钮 → 需要再点一次「确认清空」才真正执行。
    • 
          

        

        

          
🖼️ 图片为什么会自动存下来

          
QQ 返回的媒体链接是带签名的短时效地址，过期后无法再换取。所以机器人收到图片/表情包/文件时会
            立刻下载到 data/media/ 并入库，网页始终引用本地副本，
            点开大图、保存都不会失效。

        

        

          
👥 群管理与禁言

          
    
            
  • 官方禁言接口：POST /v2/groups/{群}/restrict_chat_setting，要求机器人是群管理员，最长 30 天。
    • 
            
  • 「禁言方式」可设为：本地（机器人不回复该成员）/ 官方接口 / 两者都做。
    • 
            
  • 群成员列表若提示平台未开放（11253 白名单），仍会显示从历史消息里识别到的成员。
    • 
          

        

        

          
🔐 安全提示

          
    
            
  • 默认只监听 127.0.0.1。改成 0.0.0.0 前务必在「设置 → 网页后台」填一个随机访问令牌。
    • 
            
  • 本程序会把 AppSecret / API Key 保存在 config.json 里（网页显示为掩码）。
    • 
          

        

        

          
🧩 插件

          
把 .py 文件或文件夹放进 plugins/，用「插件管理」页重载即可。
             支持 PLUGIN / COMMANDS / KEYWORDS / match() /
             on_message(msg, bot) / on_start / on_stop。
